C++ FUNCTION DEBUGGING PRACTICE
================================

Instructions:
Find and fix the error(s) in each program.


Question 1: Missing Return Statement
-------------------------------------

#include <iostream>
using namespace std;

int add(int a, int b) {
    cout << a + b;
}

int main() {
    int result = add(5, 3);
    cout << result;
    return 0;
}
